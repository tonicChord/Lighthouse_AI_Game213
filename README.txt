Beacon of the Storm V8

Open beacon_of_the_storm_V8.html. Open Sound off > Enable sound to start audio. Adjust the master, storm, effects and voice sliders in that panel.

Each pair alternates on successive events. Storm tracks alternate when each finishes. Both arrival voice recordings alternate. Voice lines are queued and repeated announcements are limited. Storm volume ducks under speech. Warning sounds trigger when energy crosses 20%, and rearm above 25%. Muting stops all audio; enabling starts the next storm track. Restart clears pending sounds and voices while retaining each pair’s alternating order.

Keep Audio beside this HTML, or copy the HTML into the original project Scripts folder to load ../Audio. Assets and SpreadSheets are included. Browser restrictions can require manual asset/balance imports through Dev tools. Internet is needed for the existing spreadsheet library and utility styling.

No new audio was generated. AUDIO-MAPPING.json lists all supplied tracks.

Validation: simulated DOM and media tests passed for audio unlocking, alternate variants, ambient sequencing, voice queue, cooldowns, mute, volume mixing, warning thresholds, restart, and file fallback. Audible browser playback has not been verified.
